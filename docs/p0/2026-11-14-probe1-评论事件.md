# P0 探针 #1:评论事件接口验证记录

- 配置: /home/ubuntu/workspace/super-agent/tools/probe/probe_config.json
- 模式: dry-run

## create_doc

- 命令: `lark-cli docs +create --title P0探针-评论事件测试文档 --as user`

## subscribe

- 命令: `lark-cli openapi post /open-apis/drive/v1/user/subscription --body {"event_type":"drive.notice.comment_add_v1"}`

- 断言: 返回 200 且不含 error
## first_comment

- 命令: `lark-cli drive +add-comment --doc docx_TEST --content P0探针首评 --as user`

## second_reply

- 命令: `lark-cli drive +reply-comment --doc docx_TEST --comment-id {first_comment_id} --content P0探针二次回复 --as user`

## listen

- 命令: `lark-cli event consume --timeout 120 --out docs/p0/events.ndjson`

- 断言: events.ndjson 中出现可关联 {doc_token} 的 comment_add 事件(含首评与二次回复两条,且断线重连后重复事件可识别)
## 结论(模板)

- **available**: 事件可用:评论回路走事件为主 + 低频全量对账;comment_watcher 仅留作对账工具
- **unavailable**: 事件不可用:启用 comment_watcher 轮询降级(分频+退避+配额评估,见 P0 第 8 项)
